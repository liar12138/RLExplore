# 实验实现表

所有学习方法共用资产、SONIC checkpoint、候选生成、物理成功判定与时间预算。网络比较须同时报告参数量、决策数量和墙钟时间；当前默认没有强制把 GRU 与 Transformer 参数量调成相等。

| 编号 | 研究问题 | 当前实现 | 执行方式 / 仍缺项目 |
|---|---|---|---|
| E0 | 高层之前，底层能否放置？ | 已实现无遮挡局部场景及 oracle 执行验收 | `scripts/calibrate.py --episodes 50`；与高层评估分别报告 |
| E1 | 支撑面初始在视野外，能否主动转向发现？ | 已实现；初始腰部转离，移除另一侧可见桌面 | `suite=E1`；不包含行走搜寻 |
| E2 | 遮挡的净空证据是否值得主动观察？ | 已实现桌面障碍、遮挡板、射线未知地图 | `suite=E2`；尚未保证每个随机场景都必须二次观察 |
| E3 | 尺寸变化是否改变观察/落点？ | 已实现同布局种子下 small/large/long 物体 | 同一 checkpoint、测试种子，分别设置 `suite=E3 object_variant=small/large/long`；抓持偏置变化尚缺 |
| E4 | 当前图像相同、历史不同，是否利用记忆？ | 未实现严格配对数据生成器 | 不能用普通历史长度消融代替此反事实实验 |
| E5 | 可见面积相同，是否选择任务相关的信息？ | 未实现严格观察价值配对 | 普通遮挡随机化不能证明此项 |
| E6 | 几何不变、观察成本变，是否改变停止决策？ | 已有 time_cost 与 observe_seconds 参数及命令表中的成本消融 | 尚未实现严格配对成本评估协议，不接受 `suite=E6` |
| E7 | 技能超时后是否恢复？ | 已实现每次有效提交 20% 超时注入，持物不释放 | `suite=E7`；尚无随机底层权重扰动或复杂恢复规划 |
| E8 | 新房型/资产/材质泛化？ | 未实现独立房型数据集 | 现有 seed split 仅为程序化布局种子划分 |
| E9 | 感知扰动的稳健性？ | 已实现 8 mm 深度噪声、5 mm 相机平移噪声 | `suite=E9`；未含 RGB 材质域随机化 |

## 方法与预算

| 对照 | 已实现 | 说明 |
|---|---|---|
| Transformer-PPO | 是 | causal mask；固定窗口上下文；pointer 候选头 |
| GRU-PPO | 是 | 与 Transformer 共用输入、融合、动作头与 PPO |
| 反应式 PPO | 是 | `backbone=reactive`，不使用时序模块 |
| TTT 风格 PPO | 是，实验变体 | 快权重记忆，非原论文完整复现 |
| 固定扫描 / 简单几何规则 | 是 | `--baseline scan/geometry` |
| 强 NBV / 滚动规划 | 否 | 后续必须补充，当前不能宣称 RL 必要性已被证明 |
| Teacher-student / 示范预训练 | 否 | 当前为高层从零 PPO |

`manifest` 生成 120 个架构实验（6 集合 × 4 网络 × 5 seeds）和 35 个消融实验，均标记 `planned`，不自动运行。默认每项 100 × 64 决策只是起始预算；正式比较需统一足够训练量并保留独立测试。

主指标：物理成功率、真实仿真耗时、观察次数、提交次数、终止原因、关节跟踪误差、机器人与桌面/障碍接触时间。`collision_seconds` 统计每个 20 ms 时刻是否存在超过 1 mm 的机器人—场景穿透，不等同于严格碰撞力或安全认证指标。尚未实现 ECE/Brier、关键证据观察率、轨迹长度和逐布局聚类置信区间。

建议先确认 E0 足够可靠，再扩大 E2 训练。E3 在相同 seed 下保留布局随机数消耗；物体变化会影响真实遮挡与物理结果，这属于条件化任务的一部分。
